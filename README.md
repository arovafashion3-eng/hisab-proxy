# হিসাব AI Proxy

Gemini API-এর জন্য একটি সহজ Vercel proxy।

## Deploy করুন

1. এই repo টি GitHub-এ upload করুন
2. vercel.com এ গিয়ে "New Project" → GitHub repo select করুন
3. Deploy চাপুন — শেষ!

Deploy হলে আপনি একটা URL পাবেন যেমন:
`https://hisab-proxy.vercel.app`

সেই URL টি হিসাব app-এর Settings-এ "Proxy URL" বক্সে দিন।
